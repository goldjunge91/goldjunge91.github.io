# 🚀 Modern 3D Portfolio Website

Eine atemberaubende, interaktive Portfolio-Website mit 3D-Effekten, Sternenhimmel-Navigation und modernen Animationen.

![Portfolio Preview](https://via.placeholder.com/800x400/0a0a0a/00f5ff?text=3D+Portfolio+Preview)

## ✨ Features

### 🔥 3D Loading Screen
- Spektakulärer Loading Screen mit Three.js
- Rotierender Energieball mit Partikel-Effekten
- Glitch- und Neon-Effekte
- Smooth Übergang zur Hauptseite

### 🌌 Interaktiver Sternenhimmel
- Animierter 3D-Sternenhimmel als Hintergrund
- Mausbewegung beeinflusst die Kamera
- Partikel-Effekte und Farbverläufe
- Responsive WebGL-Rendering

### 💫 Star Navigation
- Sterne als interaktive Buttons
- 3D-Hover-Effekte mit GSAP
- Smooth Scrolling zu Sektionen
- Partikel-Explosionen bei Klicks

### 📱 Responsive Design
- Mobile-First Ansatz
- Optimiert für alle Geräte
- Touch-freundliche Bedienung
- Flexible Grid-Layouts

### 🌗 Dark Mode Toggle
- Automatische Systemerkennung
- Smooth Theme-Transitions
- LocalStorage-Speicherung
- Anpassung aller 3D-Effekte

## 🛠️ Technologien

- **Three.js** - 3D-Grafiken und WebGL
- **GSAP** - Hochperformante Animationen
- **TailwindCSS** - Utility-First CSS Framework
- **Vite** - Moderner Build-Tool
- **Font Awesome** - Icons
- **Vanilla JavaScript** - Performance-optimiert

## 🚀 Quick Start

### 1. Repository klonen
```bash
git clone https://github.com/goldjunge91/goldjunge91.github.io.git
cd goldjunge91.github.io
```

### 2. Dependencies installieren
```bash
npm install
```

### 3. Development Server starten
```bash
npm run dev
```

### 4. Für Production builden
```bash
npm run build
```

### 5. Auf GitHub Pages deployen
```bash
npm run deploy
```
